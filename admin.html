Como colocar as alterações no ar

  1. Baixe e extraia o ZIP gerado acima.
  2. No seu repositório do GitHub, escolha Add file → Upload files. Envie os arquivos extraídos e a pasta assets; confirme em Commit changes na branch de publicação.
  3. Se for a primeira publicação, em Settings → Pages, escolha Deploy from a branch, branch main e pasta / (root). Salve.
  4. Aguarde a atualização e abra o endereço informado em Pages. Só quem tem acesso ao repositório consegue publicar.

As fotos e edições não são enviadas até você publicar os arquivos. Para fazer novas alterações, abra novamente o painel da versão publicada.
